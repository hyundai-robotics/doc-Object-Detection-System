# Object Detection System

## 10.2 Troubleshooting

If a problem occurs while using the system, refer to the following information to take appropriate action.  
If the problem is not resolved even after applying the suggested solutions, please contact the support team.

| Problem | Cause | Solution |
|---------|-------|----------|
| Detection occurs in an undesired location | The configured detection area does not match the desired detection area | Refer to the configuration change section and adjust the configuration. |
| System switches to safe state even though no object is in the detection area | No power supply | Check the power connection. Contact the support team if necessary. |
| | Failure in the control unit or one or more sensors | Check for errors (refer to the error description section). Contact the support team if necessary. |
| System does not operate properly | Control unit failure | Check for errors (refer to the error description section). Contact the support team if necessary. |
| | Sensor unit failure | Check for errors (refer to the error description section). Contact the support team if necessary. |
