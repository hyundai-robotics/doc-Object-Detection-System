# Object Detection System

## 10.5 Sensor Replacement

If a critical error is detected in one or more sensor units and the unit does not operate normally even after corrective measures, the corresponding sensor unit must be replaced.  

### Replacement Procedure
1. Turn off the power to the robot and the object detection system before replacement.  
2. Disconnect the communication and power cables connected to the faulty sensor unit.  
3. Remove the faulty sensor unit from its mounting bracket.  
4. Install the new sensor unit in the same position and secure it firmly.  
5. Reconnect the communication and power cables.  
6. Turn on the power and check using the TP (Teach Pendant) that the new sensor unit is recognized correctly.  
7. Reconfigure any necessary parameters for the newly replaced sensor unit.  

![Warning Symbol](../_assets/경고기호.png)  
The replacement must only be performed by trained personnel. Improper replacement may lead to malfunction of the entire system.
