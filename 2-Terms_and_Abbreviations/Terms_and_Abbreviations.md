# Object Detection System

## 2 Terms and Abbreviations

### 2.1 Terms

| Term | Meaning |
|------|---------|
| (Static) Residual Movement | Very small movements caused by human breathing, heartbeat, or slight tremors |
| Warning Zone | A zone in the object detection system where, if an object enters, a signal is output to stop the robot immediately |
| Stop Zone | A zone in the object detection system where, if an object enters, a signal is output to decelerate the robot in advance to mitigate risks |
