### 8.2.2	감지 대상이 감지 영역 외부로 이동했음에도 불구하고 로봇이 정상 동작하지 않음
해당 문제는 일반적으로 다음의 원인에 의해 발생한다.
-	센서의 감지 영역 내에 감지 대상 외의 다른 움직이는 객체가 존재 (로봇 등 포함)
-	센서의 진동 또는 움직임이 발생
-	존재하지 않는 객체 감지

위와 같은 원인으로 발생한 문제는 다음의 방법으로 해결할 수 있다.
-	센서의 감지 영역 내에 감지 대상 외의 다른 움직이는 객체가 존재하지 않도록 모두 제거
-	센서의 감지 영역 내에 감지 대상 외의 다른 움직이는 객체가 존재하지 않도록 센서의 감지 영역 수정
-	센서의 진동 또는 움직임이 발생하지 않도록 환경 구성
-	존재하지 않는 객체가 감지하지 않도록 레이더 객체 감지 파라미터 수정
-	전도성/금속성 객체를 최소화
