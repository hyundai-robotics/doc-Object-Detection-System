### 8.2.1	객체가 감지 영역으로 진입했음에도 불구하고 로봇이 정지하거나 감속하지 않음
해당 문제는 일반적으로 다음의 원인으로 인해 발생한다.
-	레이더 replan 기능이 활성화되지 않음
-	센서의 감지 영역 내 감지를 방해하는 장애물이 존재
-	센서의 사각지대에서 객체가 진입
-	레이더 객체 감지 파라미터가 잘못 설정되어 있음
-	감지 영역(영역1 ~ 영역4)이 잘못 설정되어 있음

위와 같은 원인으로 발생한 문제는 다음의 방법으로 해결할 수 있다.
-	레이더 replan 기능을 활성화
-	감지 영역 내에 있는 장애물 제거
-	추가적인 안전 조치를 수립하여 사각지대에서 발생할 수 있는 미감지 해결
-	동작 환경에 적합한 레이더 객체 감지 파라미터 설정
-	동작 환경에 적합한 감지 영역(영역1 ~ 영역4) 설정
-	전도성/금속성 객체를 최소화
