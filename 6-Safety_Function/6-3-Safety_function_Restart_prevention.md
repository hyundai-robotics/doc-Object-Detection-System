## 6.3  안전 기능: 재시동 방지
재시동 방지 기능이란, 움직이는 객체가 감지되어 로봇이 정지 또는 감속했을 때, 로봇의 속도가 자동으로 복구되거나 임의로 재동작하는 것을 방지하는 안전 기능이다. 로봇의 안전 관련 메인 제어 시스템으로부터 주기적으로 로봇 상태에 대한 신호를 수신하여 재시동 여부를 판단한다. 시스템이 정지 또는 감속인 상태에서 로봇의 안전 관련 메인 제어 시스템으로부터 재시동 신호를 수신하는 경우, 로봇은 원래 속도로 동작한다. 만약 시스템이 정지 또는 감속 상태가 아니거나 로봇의 안전 관련 메인 제어 시스템으로부터 재시동 신호를 수신하지 않은 경우, 현재 상태를 유지한다.
재시동 신호는 제어기의 비상 정지 스위치를 해제한 후 모터온을 해야 발생한다.
 
{% hint style="danger" %} 
반드시 레이더 검지 영역 내에 작업자가 있는지 확인한 후 재시동해야 한다.
{% endhint %}
