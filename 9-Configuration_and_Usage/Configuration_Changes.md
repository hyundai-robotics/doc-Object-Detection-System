# Object Detection System

## 9.3 Configuration Changes

![Warning Symbol](../_assets/경고기호.png)

During configuration changes, the system cannot be guaranteed to operate as intended, so safety measures are required in areas where risks may occur. If the system configuration is arbitrarily modified, the detection area may change, and the system cannot guarantee operation across the entire initially configured detection area.

### 9.3.1 Changing Detection Area Settings
1. Go to **[System]** at the bottom of the screen.  
2. Navigate to **[Safety Radar] → [Detection Information]**.  
3. From the top tab, select the ID value of the detection area to be changed.  
4. Modify the desired values.  
5. Follow the sequence **[Save] → Enter password** to store the settings.

### 9.3.2 Changing Sensor Settings
1. Go to **[System]** at the bottom of the screen.  
2. Navigate to **[Safety Radar] → [Radar Sensor Information]**.  
3. From the top tab, select the ID value of the sensor unit to be changed.  
4. Modify the desired values.  
5. Follow the sequence **[Save] → Enter password** to store the settings.
