# Object Detection System

## 4.4 Sensor Unit

### 4.4.1 Functions

The sensor unit performs the following functions:  
- Detects movement of objects within the configured detection range  
- Sends signals of detected object movement to the control unit  
- Detects faults through self-diagnosis and, if a fault is detected, transmits the information to the control unit  

### 4.4.2 Performance

The main performance specifications of the sensor unit are as follows:  

| Performance          | Minimum | Maximum |
|----------------------|---------|---------|
| Detection Distance (mm) | 500     | 5000    |
| Detection Speed (m/s)  | 0.1     | 5.0     |
| Horizontal Detection Angle (°) | ±5      | ±55    |
